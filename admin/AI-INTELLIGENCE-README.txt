NARDTOPUS Intelligence & Reports, phase 1

Open dashboard.html and select OPEN INTELLIGENCE. Live analysis requires an authenticated administrator and the existing Supabase is_omg_admin RPC. The browser report engine analyzes membership records without sending them to a third-party AI provider. Upload mode supports CSV and JSON arrays with lga, ward, polling_unit, membership_status columns. Printing uses browser Print / Save as PDF.

IMPORTANT: This release provides deterministic automated intelligence, not generative AI. To enable LLM-written narratives safely, implement a server-side Supabase Edge Function with secrets stored server-side, aggregate data only, validate outputs and apply access controls. Do not place an AI API key in client JavaScript. PDF/Excel upload parsing and time-series snapshots are future phases. Existing ID card files and print settings were not changed.
