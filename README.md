# Ochoudo Mandate Group Website

Static landing page designed for GitHub Pages.

## Files
- index.html
- style.css
- script.js
- assets/logo.png

## Deployment
1. Create a new GitHub repository named `ochoudo-mandate`.
2. Upload all files while preserving the folder structure.
3. Go to Settings > Pages.
4. Select Deploy from branch.
5. Select main branch and /(root).
6. Save.

GitHub will provide the public website URL.

## Important
Replace assets/logo.png with the official Ochoudo Mandate Group logo.
Update the placeholder NDC registration link in index.html.
Replace the Ochoudo photo placeholders when official photos are available.
